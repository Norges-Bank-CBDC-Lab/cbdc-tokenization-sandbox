# Generated NatSpec Reference

This folder contains the generated NatSpec contract reference for
[`contracts/src/`](../../src).

Start with [`src/README.md`](./src/README.md), which is the generated index for
the contract tree.

The committed pages are mdBook Markdown generated by an earlier Foundry release.
Foundry 1.8.6, the version pinned for Contracts CI, no longer emits that format:
`forge doc --out docs/natspec` now writes a Vocs site scaffold (`src/pages/*.mdx`,
`package.json`, `vocs.config.ts`, `vocs.sidebar.ts`) and leaves the mdBook tree
untouched. The Vocs output is not used here; delete it if `forge doc` creates it.

Keep the reference current by editing the affected pages under `src/src/` when a
contract's source or NatSpec comments change, then run, from `contracts/`:

```console
python3 docs/natspec/fix-links.py
```

Notes:

- The Markdown is committed alongside the source so it is browsable in the
  repository.
- `fix-links.py` rewrites root-relative links such as `/src/...` so they browse
  from the committed tree, turns each `Git Source` link into a repository-relative
  link to `contracts/src/`, and rewrites the relative links in the homepage
  (`src/README.md`, a copy of `contracts/README.md`). The script is idempotent:
  a second run changes nothing.
- `Git Source` links are relative, so they resolve at whatever commit the page is
  viewed at, and `check-markdown-links.py` validates them.
- `book/` output is intentionally ignored; generate it locally only when you
  need a built site.
